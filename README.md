# 📚 프론트엔드 개발자 신혜민의 포트폴리오

안녕하세요! 프론트엔드 개발자 신혜민입니다. 이 레포지토리는 제가 제작한 포트폴리오 웹사이트의 소스 코드를 담고 있습니다.

### 🛠️ 사용된 기술 스택

이 프로젝트는 다음과 같은 기술 스택으로 제작되었습니다.

| 분류 | 기술 |
| :--- | :--- |
| **개발 언어** | JavaScript (ES6+), TypeScript |
| **프레임워크** | React |
| **스타일링** | Tailwind CSS |
| **버전 관리** | Git, GitHub |

### ✨ 주요 기능

* **반응형 웹 디자인:** PC, 태블릿, 모바일 등 다양한 기기에서 최적화된 화면을 제공합니다.
* **직관적인 UI/UX:** 방문자가 한눈에 제 기술 스택과 경력을 파악할 수 있도록 구성했습니다.
